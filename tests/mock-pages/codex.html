Build a REST API for a todo app with Express

I'll create the Express API with CRUD endpoints for managing todos. Here's the project structure:

todo-api/
  ├── server.js
  ├── routes/
  │   └── todos.js
  ├── middleware/
  │   └── errorHandler.js
  └── package.json

The API includes GET, POST, PUT, and DELETE endpoints with proper error handling and status codes.

Add input validation with Joi

Here's the validation middleware using Joi schemas:

const Joi = require('joi');

const todoSchema = Joi.object({
  title: Joi.string().min(1).max(200).required(),
  completed: Joi.boolean().default(false)
});

Each route now validates the request body before processing. Invalid requests return a 400 status with descriptive error messages.
