What is recursion in programming?

Recursion is a programming concept where a function calls itself to solve a problem. It breaks down a complex problem into smaller, more manageable sub-problems that are essentially the same type of problem.

A recursive function typically has two parts:

  • Base case: The condition that stops the recursion
  • Recursive case: Where the function calls itself with a modified argument

Can you show me an example in Python?

Sure! Here is a classic factorial function using recursion:

def factorial(n):
    # Base case
    if n == 0 or n == 1:
        return 1
    # Recursive case
    return n * factorial(n - 1)

print(factorial(5))  # Output: 120

When you call factorial(5), it expands like this: 5 * 4 * 3 * 2 * 1 = 120.
