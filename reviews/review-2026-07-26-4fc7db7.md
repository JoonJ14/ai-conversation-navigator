## Scope

v12.0 conversation index. Claude.ai virtualizes its message list with recycling
(~3 of 147 user turns mounted), so `document.querySelectorAll()` is no longer a
complete record of the conversation. This change adds an API-backed index
(`ci*` functions) that fetches the full conversation JSON via `GM_xmlhttpRequest`,
walks the message tree from `current_leaf_message_uuid` to exclude abandoned
edit/regenerate branches, and becomes the source of truth for Navigate, Search,
Summary, and Export. The DOM scan remains as a visibly-degraded fallback.

Files:
- `ai-conversation-navigator.user.js` (modified)
- `tests/test-all-platforms.js` (modified)
- `tests/mock-pages/claude-virtualized.html` (new)

### Environment — how Tier 3 was unblocked, and a misdiagnosis worth recording

`codex exec` aborted every shell command with
`bwrap: loopback: Failed RTM_NEWADDR: Operation not permitted`, under every sandbox
mode, because Ubuntu 24.04 sets `kernel.apparmor_restrict_unprivileged_userns=1`.
Codex correctly refused to produce findings it could not verify rather than
fabricating a pass.

**The misdiagnosis.** Codex ships its own bwrap (`codex-resources/bwrap`,
integrity-checked via `CODEX_BWRAP_SHA`), which led to the conclusion that a
`/usr/bin/bwrap` profile "would do nothing". **The opposite is true.** The binary
states its own resolution order — *"no system bwrap was found on PATH and no bundled
codex-resources/bwrap binary was found next to the Codex executable"* — system-PATH
first, bundled only as fallback. `strace` settled it in one command:
`execve("/usr/bin/bwrap")` once, `codex-resources/bwrap` zero times.
**Lesson: trace the syscall before theorising about which binary runs.**

`--enable use_legacy_landlock` was also evaluated and rejected: it needs no user
namespaces and works for simple commands, but the multi-agent path fails with
*"permission profiles requiring direct runtime enforcement are incompatible with
--use-legacy-landlock"*, and the flag is already deprecated.

Resolved with `/etc/apparmor.d/codex-bwrap` (`flags=(unconfined)` + `userns,`),
modelled on Ubuntu's shipped `ch-checkns` and `linux-sandbox` profiles, with all
version/hash path segments globbed so a Codex or node upgrade cannot silently
re-break it.

**Scope note:** `/usr/bin/bwrap` is root-owned and not user-writable, but it is the
*shared* system bubblewrap — anything invoking it gains `userns`, not Codex alone.
Still far narrower than the machine-wide sysctl switch, which was explicitly
rejected because Cursor's installer rewrote `/etc/sysctl.d/50-cursor.conf` on
2026-07-23 (commenting out the overrides) and can do so again.
