## Part 1 — the Gemini index adapter (DEC-046 pattern; a new DEC supersedes DEC-057's "no adapter")

**Fetch:**
- On opening a `/app/<id>` chat: `hNvQHb` with page size 100, then follow the cursor until it's null. That's one call for chats under 100 turns; longer chats page on.
- Gem and `/u/N/` paths: no adapter. Use the fallback, and log them as unmeasured.

**Parse:**
- The `)]}'` prefix, the length-prefixed lines, and the `wrb.fr` entry for `hNvQHb`. The payload is `[turns newest-first, cursor, …]`; reverse it into conversation order.
- Per turn: the id from `turn[0][1]` (`r_<16hex>`), the question from `turn[2][0][0]`, and the answer text from the slot Phase 1 measured. Name the path in a code comment with its measurement.
- Drop the heavy rich-content slot right after extracting what's needed. Never keep the 13.5M-character string or the full parsed tree.
- Measure the parse time and peak memory on 96b519c1.

**Self-check (mandatory, every load and refresh):**
- The mounted turns' container ids and question text must match the index (id and normalized text, 100%).
- Any mismatch degrades visibly: the index banner, the v12.18 DOM behaviour, and the "older messages not loaded" note. Never show a silently wrong list.
- Also degrade on:
  - an HTTP 200 with a null payload (the session; error `[7]`);
  - error `[3]` (the arguments changed);
  - a payload whose shape doesn't parse.

**Token:**
- `at` comes from the inline script text.
- On HTTP 400: re-read it once from the current document and retry once. If it fails again, degrade with a reason.
- No ~16 s retry loop on a 400: classify it like ChatGPT's token refresh, not as transient.

**Transport code:**
- Add a POST, form-encoded path beside the GET/JSON one.
- Claude's request shape must not change: probes L1-shape and L2-shape stay green, unmodified.
- One `[ACN] index: platform=gemini transport=… endpoint=hNvQHb …` log line per request, in the adapters' format.

**Refresh:**
- After a new message, or when the mounted turns outgrow the index: fetch the newest page only (size 10) and merge by id.
- A full refetch happens only on a conversation change or a self-check mismatch.
- Gate the number of calls.

**Features from the index** (as DEC-059 did for ChatGPT and Perplexity):
- Navigate's full list on open.
- Search, Export and Summary over the whole conversation.
- The size estimate and the size dots from the index's text (`orbConvSizes`).
- The "older messages not loaded" note hidden while the index is ready.

**Regressions to avoid:**
- **Bookmarks:** they keep the `r_<id>` keys (no migration). Labels are final (Q#n) as soon as the index is ready. With a degraded or absent index they must behave exactly as v12.18 does: "Q#…" while partial and Q#n once loaded, never the adapter path's "Q#?" because an adapter merely exists.
- **The gallery** stays on its DOM path and must not empty.
- **The history tracker** (`gmHist*`) keeps running whenever the index isn't ready.

**Jumps to unloaded questions:**
- Navigate, Search, Summary and bookmarks page the DOM toward the target: scroll to the top, wait for the page, repeat until the target id mounts, then land (`gmLandFarEl`).
- Use ChatGPT's `pagesAtTop` approach with Gemini's measured timings: pages arrived in 1.5–2.9 s, plus ~4.6 s render blocks (DEC-057). Set a per-jump cap from the turn count.
- While paging, show a small "Loading earlier messages…" status, so a 10–20 s jump doesn't look frozen. This is the ChatGPT UX item from v12.17; build it for Gemini here, and log ChatGPT's own for later.

## Part 2 — the "Load full history" button (the fallback)

- **When it shows:** in Navigate, wherever older history isn't loaded and the index isn't ready: a manager without a working transport, a degraded index, Gem or `/u/N/` paths.
- **What a click does:**
  - It pages to the start (the same mechanism as the jumps) with progress text ("Loading… 20 of ?").
  - When the start is reached, it restores the user's view to the turn they were on, anchored by turn id.
  - A user scroll or a second click cancels it.
- **When it hides:** once the start is loaded (DEC-057's rules, or a null cursor when the index exists).
