# Roadmap

Future directions and ideas for AI Conversation Navigator.

This document tracks features and platform expansions we're considering but haven't started yet. It's meant to capture research, reasoning, and priorities so we (or contributors) can pick things up when the time is right.

---

## Supported Today

### AI Chatbots
- Claude (`claude.ai`)
- ChatGPT (`chatgpt.com`)
- Grok (`grok.com`)
- Gemini (`gemini.google.com`)

### Coding Agents (Web)
- Claude Code (`claude.ai/code`)
- Codex (`chatgpt.com/codex`)

### AI App-Builder Platforms (added in v7.0)
- Bolt.new (`bolt.new`) — Purple theme, ⚡ icon
- Lovable (`lovable.dev`) — Violet theme, ♥ icon
- Replit (`replit.com`) — Orange theme, ⠕ icon

**Note:** Replit selectors are speculative due to Emotion CSS-in-JS hash classes. Live DOM validation is needed — see CHANGELOG v7.0 for details. Bolt.new and Lovable selectors are based on open-source analysis and should be more stable, but all three may need tuning after live testing.
